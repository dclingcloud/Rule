# 应用配置导入导出需求文档

## 1. 文档说明

- 模块：应用配置
- 功能：应用规则导入、导出、导入模板下载、预导入分析
- 版本：v1.0
- 更新时间：2026-09-16
- 原型地址：http://172.17.206.30:10001/
- 编写依据：当前应用配置导入导出原型及已有业务场景

## 2. 建设目标

为应用配置提供批量迁移和批量维护能力，支持以下业务目标：

1. 批量导出已有应用规则，修改应用名称等配置后重新导入，不影响指标统计及既有业务关联。
2. 支持大量应用规则一次性导入，并通过数量限制和预导入分析降低异常配置风险。
3. 支持混合模式和单一模式两套规则结构，保证导入、导出和模板字段保持一致。
4. 支持 Excel 和 CSV 文件导出，便于人工查看、批量编辑和系统间交换。
5. 为后续开放 API 提供统一的导入、导出数据结构及校验规则。
6. 对导入、导出及模板下载操作记录审计日志，满足操作追溯要求。

## 3. 功能范围

### 3.1 本期范围

- 应用规则导入。
- 导入文件上传和目标接口多选。
- 混合模式、单一模式选择。
- 同名规则合并、覆盖策略选择。
- 预导入分析及失败详情展示。
- 单探针应用规则数量上限校验。
- 当前筛选结果导出。
- Excel、CSV 导出格式选择。
- 混合模式、单一模式导入模板下载。
- 导入、导出、模板下载审计记录。

### 3.2 后续扩展范围

- 通过开放 API 为通过认证的第三方提供应用规则导入、导出能力。
- API 使用与页面一致的数据结构、权限、校验、冲突处理、数量限制及审计规则。

## 4. 名词与应用模式

### 4.1 混合模式

- 定义：兼容老版规则配置的数据结构。
- 一条应用规则配置一组四元组：源 IP、源端口、目的 IP、目的端口。
- 支持源 IP、源端口、目的 IP、目的端口排除配置。
- 导入、导出及模板均使用混合模式字段结构。

鼠标悬浮模式说明图标时展示：

> 老版规则配置模式，支持一组四元组配置，支持地址或端口排除。

### 4.2 单一模式

- 定义：通过流规则字段配置一组或多组四元组，用于精准匹配多个会话。
- 支持在同一应用内配置多组四元组。
- 不支持任何地址或端口排除字段。
- 导入、导出及模板均使用单一模式字段结构。

鼠标悬浮模式说明图标时展示：

> 支持多组四元组配置，精准匹配多个会话，不支持地址或端口排除。

## 5. 页面入口与按钮

应用配置列表操作区常驻以下按钮：

- 导入配置
- 导出配置
- 下载模板

导入和导出均基于用户当前所在的协议分类、应用类型及筛选上下文执行。无操作权限的用户不展示按钮或按钮禁用，具体以权限系统规范为准。

## 6. 导入配置

### 6.1 导入弹窗

点击“导入配置”后打开导入弹窗，字段顺序如下：

1. 目标接口。
2. 应用模式。
3. 同名规则导入策略。
4. 文件上传区域。
5. 操作按钮。

### 6.2 目标接口

- 支持选择一个或多个接口。
- 至少选择一个接口，否则不能执行预导入分析。
- 导入成功后，将应用规则分发到全部已选接口。
- 修改目标接口后，已有预导入分析结果立即失效，用户必须重新分析。

### 6.3 应用模式

- 使用单选按钮选择“混合模式”或“单一模式”。
- 默认选择混合模式。
- 模式字段位于目标接口下方。
- 两个选项右侧均展示说明图标，悬浮后展示第 4 章对应说明。
- 修改应用模式后，已有预导入分析结果立即失效。
- 所选模式必须与上传文件的表头结构一致，不一致时预导入分析失败。

### 6.4 同名规则导入策略

支持以下两种策略：

| 策略 | 规则 |
| --- | --- |
| 合并配置 | 保留已有应用，并将导入配置合并到目标范围；同名应用按后端合并规则更新可合并字段，不删除未出现在文件中的应用。 |
| 覆盖配置 | 对同名应用使用导入文件中的配置覆盖已有配置；不得误删除非同名应用。 |

- 默认选择合并配置。
- 修改冲突策略后，已有预导入分析结果立即失效。
- 应用 ID、应用名称及业务关联的具体冲突判定优先级由后端接口规范统一定义。

### 6.5 文件上传

- 支持点击选择文件和拖拽上传。
- 支持格式：`.xlsx`、`.xls`、`.csv`。
- 原型展示了 `.txt` 入口；正式实现不建议支持非结构化 TXT。如需保留，必须明确分隔符、编码和字段转义规范。
- 上传后展示文件名、文件大小和上传完成状态。
- 支持移除文件并重新选择。
- 更换或移除文件后，已有预导入分析结果立即失效。
- Excel 和 CSV 中的中文内容不得乱码；CSV 建议使用 UTF-8 with BOM。

### 6.6 预导入分析

正式导入前必须先执行预导入分析。

校验范围至少包括：

- 文件格式和文件可读性。
- 表头是否与所选应用模式匹配。
- 必填字段是否为空。
- 字段值、长度和格式是否合法。
- 类型是否为 TCP、UDP、IP 或 L7。
- IP、端口、网段及流规则格式是否合法。
- 单一模式是否包含不支持的排除字段。
- 同名规则是否存在及冲突策略是否可执行。
- 目标接口是否存在且用户有操作权限。
- 导入后是否超过单探针 8000 条上限。

分析完成后展示“预导入分析报告”，报告头部展示：

- 文件名。
- 目标接口。
- 总条数。
- 成功数量。
- 失败数量。

详情区域规则：

- 仅展示分析失败的记录，不展示成功记录明细。
- 失败详情字段包括：应用名称、结果、详情。
- 结果固定为“失败”。
- 详情展示明确且可操作的错误原因，例如“应用名称为空”“类型字段需填写 TCP/UDP/IP/L7”“目的 IP 为空”。
- 全部成功时，详情区域展示“无失败详情”。
- 成功数量始终在报告汇总区域展示。

### 6.7 确认导入门禁

- 未执行预导入分析时，不展示“确认导入”按钮。
- 预导入分析存在任意失败记录时，不展示“确认导入”按钮。
- 仅当预导入分析全部成功时，才在导入弹窗和分析报告中展示“确认导入”按钮。
- 后端正式导入接口必须再次执行完整校验，不能只依赖前端分析结果。
- 分析后若文件、目标接口、应用模式或冲突策略发生变化，确认导入立即失效，必须重新分析。

### 6.8 数量限制

- 单探针应用规则总量上限为 8000 条。
- 校验公式：当前探针已有规则数 + 本次有效导入规则数不得大于 8000。
- 选择多个接口时，对每个目标接口分别校验。
- 任一目标接口超过上限时，本次导入不得执行，并明确展示超限接口、当前数量、本次数量、合计数量和上限。
- 数量校验需在预导入分析和正式导入时各执行一次，避免并发操作导致超限。

### 6.9 导入结果

导入成功后应展示：

- 应用模式。
- 导入文件名。
- 成功导入数量。
- 目标接口列表。

导入失败时不得产生部分脏数据。若业务允许部分成功，必须提供明确的事务策略、成功清单、失败清单和重试机制，本期默认采用整批校验通过后再导入。

## 7. 导出配置

### 7.1 导出数据范围

- 导出当前页面筛选条件对应的全部结果，不仅限于当前分页。
- 当筛选结果为空时，提示“当前筛选结果为空，无可导出的应用”，不打开导出弹窗。
- 导出字段值必须与 UI 配置时的业务值一致，不得直接输出后台枚举值或内部存储值。
- 示例：协议类型输出 `TCP`、`UDP`、`IP`、`L7`，不能输出内部数字枚举。

### 7.2 导出弹窗

弹窗标题为“导出应用”，包含：

1. 应用模式。
2. 文件名。
3. 文件格式。
4. 取消、确认导出按钮。

不展示“将导出当前筛选结果共 N 条应用到 Excel 文件”提示文案。

### 7.3 应用模式

- 支持混合模式、单一模式单选。
- 默认选择混合模式。
- 切换模式后，文件名默认前缀和导出字段结构同步切换。
- 模式说明与第 4 章一致。

### 7.4 文件名与格式

- 用户可修改导出文件名。
- 文件名不能为空。
- 系统过滤文件名中的非法字符：`\ / : * ? " < > |`。
- 文件名输入框右侧选择格式：`Excel` 或 `CSV`。
- 默认格式为 Excel。
- Excel 扩展名为 `.xls`，CSV 扩展名为 `.csv`。
- 切换格式时，界面展示的扩展名和实际下载文件格式必须同步变化。
- 用户在文件名中手工输入 `.xls` 或 `.csv` 时，系统应去除旧扩展名并按当前选择的格式生成最终扩展名。

默认文件名格式：

```text
{应用模式}应用_{协议分类}_{应用类型}_{YYYY-MM-DD}.{扩展名}
```

示例：

```text
混合模式应用_IPv4应用_自定义TCP_2026-09-16.xls
单一模式应用_IPv6应用_L7应用_2026-09-16.csv
```

### 7.5 表头与内容规则

- 表头使用中文或清晰的英文业务描述，禁止直接使用后台字段名。
- 可选字段在表头中增加“（选填）”说明。
- 导出表头、导入模板表头和导入解析字段必须保持一致。
- Excel 与 CSV 导出使用相同的字段顺序和业务值转换规则。
- CSV 字段需正确处理逗号、双引号和换行，避免列错位。

## 8. 导入模板下载

### 8.1 模板选择

点击“下载模板”后打开“下载导入模板”弹窗，提供：

- 混合模式应用。
- 单一模式应用。

默认选择混合模式应用。每个选项右侧展示模式说明图标。

### 8.2 模板规则

- 模板格式为 Excel。
- 模板包含表头和至少一条示例数据。
- 模板字段、顺序、格式说明必须与对应模式的导入解析规则一致。
- 混合模式与单一模式分别生成独立文件，不得共用错误的字段结构。

模板文件名：

```text
混合模式应用_导入模板_{YYYY-MM-DD}.xls
单一模式应用_导入模板_{YYYY-MM-DD}.xls
```

## 9. 字段定义

### 9.1 混合模式字段

| 序号 | 表头 | 必填 | 规则 |
| --- | --- | --- | --- |
| 1 | 应用名称 | 是 | 应用显示名称；需符合名称长度及字符规范。 |
| 2 | 应用ID | 否/按后端规则 | 用于识别已有应用及批量修改场景；新增时可由系统生成。 |
| 3 | 类型(TCP/UDP/IP/L7) | 是 | 仅允许 TCP、UDP、IP、L7。 |
| 4 | 源IP | 是 | 支持具体 IP、网段或 `any`，以实际配置规则为准。 |
| 5 | 源端口 | 是 | 支持单端口、端口段、端口集合或 `any`。 |
| 6 | 目的IP | 是 | 支持具体 IP、网段或 `any`。 |
| 7 | 目的端口 | 是 | 支持单端口、端口段、端口集合或 `any`。 |
| 8 | 源IP排除（选填） | 否 | 仅混合模式支持。 |
| 9 | 源端口排除（选填） | 否 | 仅混合模式支持。 |
| 10 | 目的IP排除（选填） | 否 | 仅混合模式支持。 |
| 11 | 目的端口排除（选填） | 否 | 仅混合模式支持。 |
| 12 | 裁包长度 | 是 | 输出并接收 UI 中的业务展示值，例如 `128字节`。 |
| 13 | 标识/备注 | 否 | 应用描述或备注。 |

### 9.2 单一模式字段

| 序号 | 表头 | 必填 | 规则 |
| --- | --- | --- | --- |
| 1 | 应用名称 | 是 | 应用显示名称。 |
| 2 | 应用ID | 否/按后端规则 | 用于识别已有应用及批量修改场景。 |
| 3 | 类型(TCP/UDP/IP/L7) | 是 | 仅允许 TCP、UDP、IP、L7。 |
| 4 | TCP流规则（格式：源IP@源端口 -> 目的IP@目的端口） | 是 | 支持一组或多组四元组；多组之间使用约定分隔符。 |
| 5 | 裁包长度 | 是 | 使用 UI 中的业务展示值。 |
| 6 | 标识/备注 | 否 | 应用描述或备注。 |

单一模式明确不包含以下字段：

- 源 IP 排除。
- 源端口排除。
- 目的 IP 排除。
- 目的端口排除。

流规则示例：

```text
1.1.1.1@1234 -> 2.2.2.2@2345; 11:22:33::1@1234 -> 22:33:44::1@3456
```

## 10. 典型业务场景

### 10.1 批量改名

1. 用户按条件筛选并导出已有应用规则。
2. 用户在 Excel 或 CSV 中批量修改应用名称，保留用于识别原应用的应用 ID。
3. 用户选择目标接口、应用模式及冲突策略后上传文件。
4. 系统根据应用 ID 识别原应用并更新名称。
5. 更新后应用的内部唯一标识和历史指标关联保持不变，不新建重复应用，不影响指标统计。

### 10.2 大量规则导入

1. 用户上传大量规则文件。
2. 系统进行文件级、行级、目标接口权限和数量上限校验。
3. 预导入报告汇总成功、失败数量，仅列出失败详情。
4. 全部校验成功后允许确认导入。
5. 任一目标接口预计超过 8000 条时禁止导入。

### 10.3 导入冲突

1. 系统识别同名或同 ID 应用。
2. 预导入报告给出冲突分析及拟执行策略。
3. 合并配置不得删除无关应用。
4. 覆盖配置仅覆盖命中的已有应用。
5. 无法安全处理的冲突作为失败记录展示，禁止确认导入。

### 10.4 第三方 API 导入导出

- 第三方调用前必须完成身份认证和权限校验。
- API 数据结构与页面模板字段含义一致。
- API 导入同样执行预校验、冲突处理和 8000 条限制。
- API 导出支持按授权范围筛选应用。
- 每次调用记录调用方、时间、范围、结果和失败原因。

## 11. 审计日志

以下操作必须写入审计日志：

- 预导入分析。
- 确认导入。
- 导出应用。
- 下载导入模板。
- 后续 API 导入和导出。

审计字段至少包括：

| 字段 | 说明 |
| --- | --- |
| 操作人 | 用户名、用户 ID；API 场景记录调用方。 |
| 操作时间 | 服务端时间。 |
| 操作类型 | 预导入分析、导入、导出、模板下载。 |
| 应用模式 | 混合模式或单一模式。 |
| 文件信息 | 上传或下载文件名、格式；可选记录文件摘要。 |
| 目标范围 | 协议分类、应用类型、目标接口、筛选条件。 |
| 冲突策略 | 合并或覆盖，仅导入记录。 |
| 数据量 | 总数、成功数、失败数。 |
| 操作结果 | 成功或失败。 |
| 失败原因 | 操作失败时记录明确原因。 |
| 请求标识 | 用于关联前端请求、后端任务和 API 调用。 |

审计日志中不得记录密码、令牌等敏感认证信息。

## 12. 异常与提示

| 场景 | 处理要求 |
| --- | --- |
| 未选择目标接口 | 提示至少选择一个目标接口。 |
| 未上传文件 | 提示先选择或拖拽文件。 |
| 文件格式不支持 | 阻止上传或分析，并提示支持的格式。 |
| 文件无法解析 | 分析失败，展示文件级错误。 |
| 表头与模式不匹配 | 分析失败，指出缺失、多余或错误字段。 |
| 存在行级错误 | 汇总失败数量，仅展示失败记录详情，不展示确认导入。 |
| 全部分析成功 | 展示成功数量和“无失败详情”，展示确认导入。 |
| 超过 8000 条 | 禁止导入，展示超限接口及数量信息。 |
| 当前筛选结果为空 | 禁止导出并提示无可导出应用。 |
| 导出文件名为空 | 禁止导出并提示输入文件名。 |
| 下载或导出失败 | 展示失败提示并记录审计日志。 |

## 13. 非功能要求

- 权限：导入、导出、模板下载权限可独立控制。
- 一致性：页面、模板、API 的字段含义和校验规则一致。
- 事务性：正式导入默认整批成功或整批失败。
- 并发：正式导入时重新校验数量上限和冲突状态。
- 性能：8000 条文件的分析和导入不得阻塞浏览器主线程；后端可采用异步任务并返回进度。
- 安全：校验文件类型、大小和内容，防止公式注入、脚本内容及恶意文件。
- 兼容性：Excel 文件可被常用办公软件正常打开；CSV 中文无乱码且字段不串列。
- 可追溯性：导入、导出及模板下载均可通过审计日志追踪。

## 14. 验收标准

### 14.1 导入

1. 可选择一个或多个目标接口。
2. 可选择混合模式或单一模式，并展示正确的悬浮说明。
3. 可选择合并配置或覆盖配置。
4. 支持上传 Excel、CSV 文件并执行预导入分析。
5. 修改文件、接口、应用模式或冲突策略后，旧分析结果失效。
6. 报告正确展示总数、成功数、失败数。
7. 报告详情仅展示失败记录，全部成功时展示“无失败详情”。
8. 存在失败记录时不展示确认导入按钮。
9. 全部成功时才展示确认导入按钮。
10. 单探针导入后超过 8000 条时禁止导入并展示明确原因。
11. 合并和覆盖策略按定义执行，不影响无关应用。
12. 批量改名后原应用指标统计和业务关联保持不变。

### 14.2 导出

1. 导出当前筛选结果的全部数据。
2. 可选择混合模式或单一模式。
3. 可选择 Excel 或 CSV，扩展名和实际文件格式一致。
4. 混合模式导出 13 个字段，并包含排除字段。
5. 单一模式导出 6 个字段，不包含任何排除字段。
6. 表头使用业务描述，不使用后台字段名。
7. 导出内容使用与 UI 一致的业务值。
8. Excel 和 CSV 中文内容正确，CSV 转义正确。
9. 空结果、空文件名等异常提示符合要求。

### 14.3 模板

1. 可分别下载混合模式应用和单一模式应用模板。
2. 两种模板字段结构、字段顺序和示例数据正确。
3. 单一模式模板不包含排除字段。
4. 模板可用于对应模式的预导入分析和正式导入。

### 14.4 审计与 API

1. 逐项验证预导入分析、确认导入、导出、模板下载均写入审计日志。
2. 审计日志包含操作人、范围、模式、文件、数量和结果。
3. API 导入导出使用与页面一致的权限、校验、限制和审计规则。

## 15. 原型与正式实现说明

当前原型用于确认页面布局、字段结构、交互门禁和结果展示。正式开发时需特别补齐以下能力：

- 使用真实 Excel、CSV 解析替代原型模拟数据。
- 由后端统一执行字段校验、冲突分析、数量校验和事务导入。
- 明确应用 ID 在批量改名场景中的稳定标识规则。
- 明确合并配置的字段级合并策略。
- 落地审计日志查询及权限控制。
- 提供第三方 API 的认证、限流、幂等和接口文档。
